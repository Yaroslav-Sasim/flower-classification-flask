Flower Image Classification App

Веб-приложение на **Flask** для автоматического распознавания видов цветов по фотографиям с использованием сверточной нейронной сети (CNN). Разработано в рамках университета.

---

## Особенности

- **Загрузка изображений:** Загрузка пользовательских фото через веб-интерфейс.
- **Инференс нейросети:** Определение класса цветка и вывод вероятности предсказания.
- **Поддерживаемые классы:** Роза, Ромашка, Одуванчик, Подсолнух, Тюльпан *(укажите свои классы)*.
